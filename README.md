# 紅樓夢諸本對校 · IIIF 善本画像検索システム（Pilot Showcase）

清代『紅樓夢（石頭記）』古鈔本群の **IIIF Presentation API v3 + 文字単位座標（`#xywh`）横断検索パイロット公開版** です。

- **公開デモサイト (Live Demo)**: https://oushiei120.github.io/hongloumeng-iiif-demo/
- **IIIF v3 Collection**: https://oushiei120.github.io/hongloumeng-iiif-demo/guji/iiif/3/collection.json

## 収録善本・公開範囲

- **IIIF v3 画像マニフェスト公開（パブリックドメイン清代古鈔本原葉・先行公開代表回 462 葉直連 / 全 3,744 葉整備済）**:
  - 甲戌本 (`jiaxu`, 489葉) / 己卯本 (`jimao`, 996葉) / 庚辰本 (`gengchen`, 955葉) / 舒序本 (`shuxu`, 1,242葉) / 鄭蔵本 (`zheng`, 62葉)
- **先行公開横断検索・対応葉推定範囲**:
  - 第一回〜第三回、および第二十三回〜第二十四回（簡体字・日本語 UI 切替、繁体字・簡体字・日本新字体・鈔本異体字による一括横断検索、大幅な異文や OCR 誤読箇所を前後文アンカーから特定する「対応葉推定（青破線枠）」、W3C Web Annotation JSON-LD / CSV 出力、Mirador 3 連携に対応）。
